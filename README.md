# 蓝色花海 · 我们

双击 `index.html` 即可打开网站，不需要安装软件。

## 功能

- 填写两个人的名字和纪念日，实时显示在一起的天数。
- 点击照片框上传照片；“再添一张照片”可以继续增加照片框。
- 上传最后一张空照片后，照片墙会自动增加下一张照片的位置。
- 点击“导入 MP3”，选择手机或电脑里的本地 `.mp3` 文件。
- 歌曲保存在浏览器音乐库中，刷新网页后仍可继续播放。
- 点击“收听我们的歌”可以切换播放或暂停。
- 故事簿支持新增、修改和删除故事。
- “编辑我们的约定”可以修改或增加愿望清单内容。
- 点击“收下今天的小情书”可以阅读、编辑和查看历史版本。
- 每次保存小情书都会新增一个版本，历史内容不会被覆盖。
- 编辑页可以删除当前版本，历史列表也可以删除指定版本。
- 情书、每日情话和愿望勾选状态会自动保存。

名字、照片、歌曲、故事和约定保存在当前浏览器中。
